Game Audio Design And Implementation

This video is a short demonstration of my honours project that I created in my final year of university. A demo game level was created in Unreal 5 using asset packs and then game functionality was programmed using Blueprints. Wwise was used to integrate audio into the game and REAPER was used to design the sounds.

UE5 Audio Implementation
